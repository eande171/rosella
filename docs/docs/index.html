Overview

Getting started

Rosella is a small scripting language that compiles to Batch for Windows and Bash for Linux. You write one .rosella file, and the compiler writes a .bat or .sh script that you run like any other.

Install

Download rosella-windows.zip or rosella-linux.zip from the latest release. Each holds one program, rosella. Unzip it somewhere on your PATH. You can also build it from source with cargo build --release.

Your first script

Save this as hello.rosella:

print("Hello World!");
Hello World!

Then compile it:

rosella compile -i hello.rosella

On Windows this writes hello.bat. On Linux it writes hello.sh. Run it the usual way, with hello.bat or bash hello.sh.

Every example on this page has tabs for the Batch and Bash it compiles to. They are compiled live in your browser by the real compiler, so they always match the current version. You can also try your own scripts in the playground.

Overview

Command line

The compiler has one command, compile:

rosella compile -i <FILE> [-o <FILE>] [-t windows|linux] [-s batch|bash]
OptionMeaning
-i, --inputThe Rosella script to compile. Required.
-o, --outputWhere to write the result. By default the input name ending in .bat or .sh.
-t, --targetThe operating system the script is for, windows or linux. This decides which with blocks are kept and which way paths are written. By default, the system you are on.
-s, --shellThe shell to write, batch or bash. By default Batch on Windows and Bash anywhere else.
-h, --helpShow help.
-V, --versionShow the version.

To write both scripts from one machine:

rosella compile -i hello.rosella -t windows -s batch
rosella compile -i hello.rosella -t linux -s bash

Batch is only available for the windows target. If there is a mistake in the script, the compiler prints it with a line and column, writes nothing, and exits with code 1:

Error during compilation: line 2, column 1: 'count' is int and cannot take a str value

Language

Basics

Every statement ends with a semicolon. Blocks such as if, loops and functions use braces and do not need one after the closing brace. Comments are written /* like this */ and can span several lines.

There are two types. int holds a whole number and str holds text. A variable is declared once with let and its type, and changed with =:

/* Variables */
let str name = "Ada";
let int age = 36;
age = age + 1;

print("Hello ", name, ", next year you are ", age);
print("Escapes: \"quotes\", a\ttab and a backslash \\");
print();
print("Two\nlines");
Hello Ada, next year you are 37
Escapes: "quotes", a	tab and a backslash \

Two
lines
  • print() takes any number of values, joins them and ends the line. With nothing inside it prints an empty line.
  • Text understands four escapes: \", \\, \n for a new line and \t for a tab.
  • An int can be used where text is expected, but text cannot be stored in an int. Use number() for that.
  • Every let declares its variable for the whole script, including ones inside functions, so each name is declared only once.
Batch cannot hold " or a line break inside a variable, path or argument. Rosella reports this as an error when compiling for Batch. print() and the text written by write_file() accept both.

Language

Numbers

Numbers are whole numbers that fit in 32 bits, from -2147483648 to 2147483647. Arithmetic uses +, -, *, / and %. Division rounds towards zero.

let int a = 17;
let int b = 5;
print(a + b, " ", a - b, " ", a * b, " ", a / b, " ", a % b);
print(2 + 3 * 4, " ", (2 + 3) * 4, " ", 0 - a, " ", -3 * 2);

let str typed = " 42 ";
if is_number(typed) {
    print("As a number: ", number(typed) + 1);
}
print(number("abc"), " ", number("007"));
22 12 85 3 2
14 20 -17 -6
As a number: 43
0 7
  • A minus sign works directly in front of a number, like -3. To negate a variable, write 0 - a.
  • number(text) turns text into a number. It accepts an optional minus sign and digits, ignores spaces around them, and reads leading zeros as normal decimal. Anything else gives 0.
  • is_number(text) checks the same rule, so a script can tell a typed 0 from bad input.

Language

Conditions

if, else if and else work as in C, without brackets around the condition. Comparisons, &&, || and ! can only be used in if and while conditions.

let int score = 72;
let str grade = "";

if score >= 90 {
    grade = "A";
} else if score >= 70 {
    grade = "B";
} else {
    grade = "C";
}
print("Grade: ", grade);

if grade == "B" && !(score == 75) || score > 100 {
    print("A B, but not exactly 75");
}

if contains("Hello World", "World") && not_exists("missing.txt") {
    print("Text and file checks work in conditions too");
}
Grade: B
A B, but not exactly 75
Text and file checks work in conditions too
  • Both sides of a comparison must have the same type.
  • Text can be compared with ==, !=, < and >.
  • The right side of && and || only runs when it is needed.
  • The checks exists, not_exists, is_file, is_dir, contains and is_number can only be used in conditions.

Language

Loops

while repeats while its condition is true. for counts through a range of numbers or walks through files. break leaves the loop and continue skips to the next round.

let int tries = 0;
while tries < 3 {
    tries = tries + 1;
    print("Try ", tries);
}

for int i in range(0, 10, 3) {
    print("i = ", i);
}

for int i in range(5, 0, -1) {
    if i == 4 {
        continue;
    }
    if i == 2 {
        break;
    }
    print("Counting down: ", i);
}

make_dir("logs");
write_file(path("logs", "one.log"), "x");
write_file(path("logs", "two.log"), "x");
let int logs = 0;
for str file in files("logs", "*.log") {
    logs = logs + 1;
}
print("Log files: ", logs);
Try 1
Try 2
Try 3
i = 0
i = 3
i = 6
i = 9
Counting down: 5
Counting down: 3
Log files: 2
  • range(start, end) counts from start up to but not including end. An optional third value is the step, which must be a written number other than 0, such as 2 or -1.
  • The end of a range is worked out once, before the loop starts.
  • files(...) joins its values into a path, like path(), and gives each matching file in turn. The last part is a pattern where * and ? are wildcards. Folders are skipped, and so are names starting with a dot unless the pattern starts with one.
  • Wildcards only work when written directly into files(). A * or ? in any other path is an error, and one held in a variable matches nothing.

Language

Functions

Functions are declared with fn. Every parameter has a type. A function that gives back a value has its return type before its name.

fn greet(str name, int times) {
    for int i in range(0, times) {
        print("Hi ", name);
    }
}

fn int largest(int a, int b) {
    if a > b {
        return a;
    }
    return b;
}

fn str describe(int n) {
    if n < 0 {
        return "negative";
    } else {
        return "not negative";
    }
}

greet("Sam", 2);
print(largest(4, 9), " is ", describe(largest(4, 9)));
Hi Sam
Hi Sam
9 is not negative
  • A function with a return type must end with return, or return in both branches of a final if and else.
  • Functions can be called before they are defined.
  • Parameters belong to their function. Variables declared with let are shared by the whole script.
  • A function cannot call itself, directly or through other functions, when compiling for Batch, because Batch variables have no call stack.

Language

Text

Text is joined with concat(), or by giving print() several values.

let str text = "Hello World";

print(length(text));
print(slice(text, 0, 5), "|", slice(text, 6, 100), "|", slice(text, -5, 3));
print(replace(text, "o", "0"));
print(upper(text), " ", lower(text));

let str joined = concat(text, " has ", length(text), " characters");
print(joined);

if contains(text, "World") && !contains(text, "world") {
    print("contains() is case sensitive");
}
11
Hello|World|Wor
Hell0 W0rld
HELLO WORLD hello world
Hello World has 11 characters
contains() is case sensitive
  • slice(text, start, count) takes count characters from start, which counts from 0. A negative start counts back from the end.
  • replace() and contains() match upper and lower case exactly.
  • upper() and lower() change the letters A to Z and leave others alone.

Language

Files and folders

Functions that take a path accept several values and join them with the right separator for the target, so path("logs", "today.txt") becomes logs\today.txt on Windows and logs/today.txt on Linux. / and \ inside the values are converted too.

let str project = "demo";
make_dir(project, "build", "out");

write_file(path(project, "notes.txt"), "first line");
append_file(path(project, "notes.txt"), "second line");
copy(path(project, "notes.txt"), path(project, "build", "copy.txt"));
move(path(project, "build", "copy.txt"), path(project, "moved.txt"));

if is_dir(project, "build") && is_file(project, "moved.txt") && exists(project, "notes.txt") {
    print("Folders and files are in place");
}

let str start = get_cwd();
cd(project);
if is_file("notes.txt") {
    print("cd moved into the folder");
}
cd(start);

remove(path(project, "moved.txt"));
remove_dir(project, "build");
remove_dir(project);
if not_exists(project) {
    print("Cleaned up");
}
Folders and files are in place
cd moved into the folder
Cleaned up
  • make_dir() creates every missing folder along the path.
  • write_file() replaces the file and append_file() adds to it. Each ends with a line break.
  • remove() only removes files and remove_dir() only removes folders, with everything inside them. Both do nothing if the path does not exist.
  • If a variable in the path given to remove() or remove_dir() is empty, the script stops with exit code 1 instead of removing the wrong thing.
  • copy() copies files and skips folders. move() moves or renames both.
  • get_cwd() gives the current folder and script_dir() gives the folder the script is in.

Language

Input and environment

let str name = read("Name: ");
print("Hi ", name);

print("Arguments: ", arg_count());
let int i = 1;
while i <= arg_count() {
    print("Argument ", i, " is ", arg(i));
    i = i + 1;
}

set_env("GREETING", "hello");
print("GREETING is ", env("GREETING"));
if env("ROSELLA_DOCS_UNSET") == "" {
    print("An unset variable is empty");
}
Name: Hi Sam
Arguments: 2
Argument 1 is first
Argument 2 is second one
GREETING is hello
An unset variable is empty

That output comes from typing Sam and running the script with the arguments first and "second one".

  • read(prompt) shows the prompt and returns the line that was typed, keeping spaces at the start. It can also be used on its own, as read("Press enter to continue");.
  • arg(n) gives argument n, counting from 1. A missing argument is empty.
  • env("NAME") and set_env("NAME", value) read and change environment variables. The name must be written in quotes. Changes last until the script ends and are seen by programs it runs.

Language

Running programs

let int status = run("git", "--version");
if status == 0 {
    print("git is installed");
}

let str branch = run_output("git", "rev-parse", "--is-inside-work-tree");
if branch != "true" {
    print("Not inside a git repository");
}

let int dice = random(1, 6);
if dice >= 1 && dice <= 6 {
    print("Rolled between 1 and 6");
}

sleep(1);
print("Waited one second");
exit(3);
git version 2.39.1.windows.1
git is installed
Not inside a git repository
Rolled between 1 and 6
Waited one second
  • run(program, arguments...) runs a program, lets it print as normal, and gives back its exit code. It can also be used on its own.
  • run_output(program, arguments...) gives back the first line the program prints that has text in it.
  • Arguments are passed exactly as written, including spaces, %, !, ^, & and a backslash at the end.
  • random(min, max) gives a number from min to max, including both.
  • exit(code) stops the script with that exit code, even from inside functions and loops. A script that ends without exit() exits with 0.

Language

Platforms and raw lines

A with windows or with linux block is only kept when compiling for that target. A line starting with |> is copied into the output exactly as written, up to its last semicolon, for anything Rosella does not cover.

let str separator = "/";
with windows {
    separator = "\\";
}
print("This system separates folders with ", separator);
print("path() picks the right one for you: ", path("a", "b"));

with windows { |> echo A raw shell line; }
with linux { |> echo A raw shell line; }

if length(script_dir()) > 0 {
    print("The script knows its own folder");
}
This system separates folders with /
path() picks the right one for you: a/b
A raw shell line
The script knows its own folder

That output is from Linux. On Windows the first two lines show \ and a\b.

Rosella does not check raw lines. Keep them inside a with block for the shell they are written for.

Reference

Names you cannot use

Some names would break one of the two shells, so the compiler rejects them with a message saying why:

  • Names starting with rosella_, which the compiler uses itself.
  • Names of built-in functions, for your own functions.
  • Shell commands the generated scripts rely on, such as mkdir, printf, read, cd or coproc, for your own functions.
  • Shell variables, such as PATH, HOME, GROUPS or TEMP, for your variables.
  • Two names that only differ by upper and lower case, such as count and Count, because Batch treats them as the same.

Reference

Batch and Bash differences

The Batch and Bash output of a script print the same text and exit with the same code. These are the known exceptions, each checked by running both shells:

SituationBashBatch
run() of a missing programGives 127Gives 1
A " in a value passed to run()The program gets itThe quotes are dropped
Numbers past 32 bitsKeep growingWrap around
< and > on numbers over 2.1 billion apartCorrectCan give the wrong answer
< and > on text that differs in case"B" < "a""a" < "B"
length() and slice() with letters like éCount characters on LinuxCount bytes
slice() starting before the textGives nothingStarts at the first character
exit() outside 0 to 255Wraps, so 300 becomes 44Keeps the number
Files written by write_file()Unix line endingsWindows line endings
Several lines piped into read()Each read() gets the next lineOnly the first line arrives
make_dir() with * or ? in a variableCreates that name on LinuxFails, Windows forbids it

Checking a run() result with != 0, keeping exit() codes between 0 and 255, and comparing text with matching case all work the same in both. Typing at the keyboard and redirecting a file into a script with < both work with several read() calls in Batch.
