Cross Platform Scripting

Write it once.
Run it on both shells.

Rosella is a small scripting language with C-style syntax. It compiles to Batch for Windows and Bash for Linux, checks your script before anything runs, and makes both outputs behave the same way.

Why Rosella

Readable

while x < 100 { } instead of while [[ $x -lt 100 ]]; do or a goto loop in Batch.

Checked First

Types, typos and unknown names are reported with a line and column before any script is written.

Same Behaviour

Both outputs print the same text and exit with the same code, even with !, % or & in your data.

Tiny Compiler

One program under 1MB with no dependencies. Compile for either shell from either system.

Get started

01

Download rosella-windows.zip or rosella-linux.zip from the latest release and unzip it somewhere on your PATH.

02

Write a script in hello.rosella:

print("Hello World!");
03

Compile it. You get hello.bat on Windows and hello.sh on Linux:

rosella compile -i hello.rosella
